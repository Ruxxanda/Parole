# 🔐 Verificare Parolă

Un site simplu care verifică o parolă și trimite datele în Google Sheets.

## 🧩 Ce face
- Are două câmpuri: **nume** și **parolă**
- Verifică dacă parola conține:
  - o literă mare (A–Z)
  - o literă mică (a–z)
  - o cifră (0–9)
  - un semn special (. - _)
- Dacă lipsește ceva → afișează mesaj roșu
- Dacă totul e corect → trimite datele în Google Sheets și duce la `gata.html`

## 📂 Fișiere
- `index.html` – pagina principală  
- `style.css` – design simplu  
- `script.js` – verifică parola și trimite datele  
- `gata.html` – pagină de confirmare  
- `Code.gs` – cod pentru Google Apps Script  

## ⚙️ Cum se folosește
1. Deschide fișierul `index.html`
2. Introdu numele și parola
3. Apasă pe **Trimite**
4. Dacă parola e bună → se salvează în Google Sheets
